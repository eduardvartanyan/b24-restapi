# Инструкция эксперта Форсайта по проверке качества ремонта

Статус документа: основа для последующей детализации и добавления скриншотов.

## 1. Назначение инструкции

Эксперт проверяет качество выполненного ремонта, фиксирует результат в задаче Битрикс24 и при необходимости прикладывает фотографии и документы.

Эксперт не ведет сделку по стадиям и не переносит результат в поля CRM: это делает ответственный менеджер.

## 2. Получение задачи

Эксперт получает штатное уведомление Битрикс24 о задаче с названием:

```text
[ФИО клиента] [Марка, модель а/м]: Провести проверку качества ремонта
```

1. Откройте уведомление или раздел «Задачи».
2. Найдите назначенную задачу.
3. Проверьте крайний срок и описание.
4. Ознакомьтесь с доступными данными по автомобилю и ремонту.

## 3. Подготовка к проверке

До начала проверки:

- уточните место и время осмотра;
- изучите перечень заявленных повреждений и выполненных работ;
- при необходимости запросите у менеджера дополнительные документы;
- убедитесь, что автомобиль доступен для осмотра.

Если данных недостаточно, оставьте комментарий в задаче и свяжитесь с постановщиком. Не завершайте задачу без результата проверки.

## 4. Проведение проверки

Проверьте:

1. фактически выполненные работы;
2. отремонтированные или замененные узлы;
3. наличие видимых дефектов и замечаний;
4. соответствие результата заявленному объему ремонта;
5. необходимость повторной проверки;
6. рекомендации клиенту по приемке автомобиля.

## 5. Фиксация результата

Оставьте комментарий к задаче строго по шаблону:

```text
Итог проверки: [принято без замечаний / есть замечания / требуется повторная проверка]
Проверенные работы и узлы: [перечень]
Выявленные замечания: [описание или "нет"]
Рекомендации клиенту: [описание или "нет"]
Повторная проверка: [не требуется / требуется до ДД.ММ.ГГГГ]
```

Правила заполнения:

- используйте только один вариант итогового результата;
- перечисляйте проверенные работы конкретно;
- если замечаний нет, напишите «нет»;
- если нужна повторная проверка, обязательно укажите срок;
- рекомендации формулируйте так, чтобы менеджер мог передать их клиенту без дополнительного уточнения.

> [Скриншот 4. Пример правильно заполненного комментария]

## 6. Добавление файлов

При наличии приложите к задаче:

- фотографии результата ремонта;
- фотографии выявленных замечаний;
- акты, заключения или другие документы.

Названия файлов должны позволять понять их содержание без открытия.

> [Скриншот 5. Добавление файлов к задаче]

## 7. Завершение задачи

Перед завершением проверьте:

- комментарий заполнен по шаблону;
- итог проверки выбран однозначно;
- все замечания описаны;
- срок повторной проверки указан при необходимости;
- фотографии и документы приложены.

После этого завершите задачу. Ответственному менеджеру автоматически будет поставлена задача перенести результат в сделку.

> [Скриншот 6. Завершение задачи]

## 8. Что происходит после завершения

Дальнейшие действия выполняет менеджер:

| Результат эксперта | Дальнейший маршрут сделки |
| --- | --- |
| Принято без замечаний | Менеджер сообщает клиенту о готовности ТС, затем сделка переходит в «Расчеты» |
| Есть замечания | Сделка возвращается на стадию «Ремонт» |
| Требуется повторная проверка | Создается новый цикл стадии «Проверка качества» |

Эксперт не должен самостоятельно менять стадии сделки.

## 9. Типовые ошибки

| Ошибка | Как исправить |
| --- | --- |
| Результат указан не по шаблону | Отредактировать комментарий до завершения задачи |
| Не перечислены проверенные узлы | Добавить конкретный перечень |
| Есть замечания, но они не описаны | Зафиксировать каждое замечание и приложить фото |
| Нужна повторная проверка без даты | Указать срок повторной проверки |
| Задача завершена ошибочно | Сразу сообщить постановщику и добавить уточняющий комментарий |

## 10. Краткий чек-лист эксперта

- [ ] Открыта правильная задача и проверен автомобиль.
- [ ] Проверены заявленные работы и узлы.
- [ ] Комментарий заполнен по утвержденному формату.
- [ ] Замечания и рекомендации сформулированы однозначно.
- [ ] При необходимости указана дата повторной проверки.
- [ ] Фотографии и документы приложены.
- [ ] Только после этого задача завершена.
