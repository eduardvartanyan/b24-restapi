# Инструкция администратора направления «Ремонт ТС»

Статус документа: основа для последующей детализации и добавления скриншотов.

## 1. Назначение инструкции

Инструкция описывает подключение новой СТОА и ее мастеров к процессу «Ремонт ТС» в Битрикс24.

Администратор направления создает и связывает пять сущностей:

1. компанию CRM с типом «СТОА»;
2. экстранет-пользователя мастера;
3. ресурс онлайн-записи мастера;
4. график работы ресурса;
5. элемент универсального списка «Связь ресурсов СТОА».

Работа считается завершенной только после контрольной онлайн-записи и проверки задачи, календаря и уведомления мастера.

## 2. Необходимые права и исходные данные

До начала работы проверьте наличие доступа к:

- CRM-компаниям;
- управлению пользователями и экстранетом;
- разделу «Онлайн-запись»;
- универсальному списку «Связь ресурсов СТОА»;
- настройке графиков ресурсов.

Подготовьте следующие данные:

- название, адрес и телефон СТОА;
- график работы СТОА;
- условия комиссии и ответственного Форсайта;
- ФИО, телефон и электронную почту мастера;
- рабочий график мастера;
- `Max ID` мастера.

> [Скриншот 1. Разделы Битрикс24, необходимые администратору]

## 3. Общая последовательность подключения

Подключайте сущности строго в следующем порядке:

1. Создайте карточку СТОА.
2. Создайте экстранет-пользователя мастера.
3. Подключите мастера к MAX-боту и заполните `Max ID`.
4. Создайте ресурс онлайн-записи.
5. Настройте график ресурса.
6. Получите ID ресурса.
7. Создайте элемент списка сопоставлений.
8. Выполните контрольную онлайн-запись.

## 4. Создание СТОА

1. Откройте раздел CRM-компаний.
2. Создайте новую компанию.
3. Укажите тип компании «СТОА».
4. Заполните карточку:
   - название;
   - адрес;
   - телефоны;
   - график работы;
   - условия комиссии;
   - ответственный;
   - комментарий при необходимости.
5. Сохраните карточку.
6. Запишите ID компании: он понадобится для диагностики связей.

Правила:

- название должно быть уникальным и понятным менеджерам;
- адрес нужно заполнять структурированно, так как он используется в сообщениях клиенту;
- тип ресурса онлайн-записи должен в точности совпадать с названием СТОА;
- при переименовании СТОА необходимо также переименовать тип ресурсов.

## 5. Создание экстранет-пользователя мастера

1. Создайте или пригласите внешнего пользователя в экстранет.
2. Укажите реальные ФИО, телефон и электронную почту мастера.
3. Убедитесь, что пользователь активен.
4. Не предоставляйте пользователю доступ к CRM.
5. Проверьте, что пользователю доступны задачи и личный календарь.

Один экстранет-пользователь может быть связан с несколькими ресурсами, но в рабочем контуре рекомендуется отдельная учетная запись для каждого мастера.

## 6. Подключение мастера к MAX

1. Попросите мастера запустить бота `@id381250859808_bot` в MAX.
2. Получите `Max ID` пользователя установленным способом.
3. Откройте профиль экстранет-пользователя.
4. Заполните поле `Max ID` (`UF_USR_1785748307515`).
5. Сохраните профиль.

Без `Max ID` система не отправит мастеру сообщение о назначении и напоминание после дефектовки.

## 7. Создание ресурса онлайн-записи

1. Откройте раздел «Онлайн-запись».
2. Создайте новый ресурс специалиста.
3. В поле типа ресурса укажите точное название СТОА.
4. В названии ресурса укажите имя мастера, например «Илья Иванов».
5. Сохраните ресурс.

Пример:

```text
Тип ресурса: Кузя
Название ресурса: Илья Иванов
```

Не добавляйте имя СТОА повторно в название ресурса: оно уже отображается как тип ресурса.

> [Скриншот 8. Создание ресурса и правило именования]

## 8. Настройка графика мастера

1. Откройте настройки созданного ресурса.
2. Укажите рабочие дни и часы приема.
3. Настройте перерывы и исключения, если они известны.
4. Проверьте длительность услуги «Дефектовка».
5. Откройте календарь онлайн-записи и убедитесь, что свободные слоты отображаются корректно.

График ресурса является источником доступности мастера. Отдельный календарь вручную не создается.

> [Скриншот 9. График ресурса]

> [Скриншот 10. Свободные слоты мастера]

## 9. Получение ID ресурса

1. Откройте публичную страницу `https://review.avarcomf.ru/api/b24/booking/resources`.
2. Найдите ресурс по имени. Каждая строка имеет формат `Название – ID`.
3. Сохраните ID: он понадобится для элемента списка сопоставлений.

> [Скриншот 11. Где посмотреть ID ресурса]

Не используйте имя мастера вместо ID: интеграция сопоставляет записи только по числовому идентификатору ресурса.

## 10. Создание элемента списка сопоставлений

1. Откройте универсальный список «Связь ресурсов СТОА».
2. Создайте новый элемент.
3. Заполните поля:
   - название ресурса;
   - ID ресурса онлайн-записи;
   - СТОА;
   - ID экстранет-пользователя;
   - пользователь, если поле позволяет выбрать экстранет-пользователя;
   - активность связи — «Да»;
   - служебный комментарий при необходимости.
4. Сохраните элемент.

Перед сохранением убедитесь, что для ID ресурса нет другого активного элемента. Один ресурс должен иметь ровно одно активное сопоставление.

## 11. Контрольная проверка

1. Создайте тестовую сделку или используйте согласованную тестовую карточку.
2. Выберите созданную СТОА.
3. Создайте онлайн-запись на нового мастера.
4. Проверьте, что:
   - сделка перешла на стадию «Дефектовка»;
   - в сделке сохранилась правильная СТОА;
   - мастеру создалась задача;
   - задача появилась у мастера и содержит правильные данные;
   - запись появилась в календаре мастера;
   - мастер получил сообщение в MAX;
   - клиент получил подтверждение записи.
5. Удалите или корректно завершите тестовые данные после проверки.

> [Скриншот 14. Результат контрольной онлайн-записи]

## 12. Изменение и отключение мастера

При изменении графика обновите график ресурса.

При смене СТОА:

1. измените тип ресурса;
2. измените компанию в элементе сопоставления;
3. выполните контрольную запись.

При отключении мастера:

1. убедитесь, что у него нет будущих записей;
2. отключите или скройте ресурс;
3. установите активность сопоставления «Нет»;
4. деактивируйте экстранет-пользователя только после завершения его задач.

Не удаляйте историю задач и сопоставлений без необходимости.

## 13. Типовые ошибки

| Ошибка | Возможная причина | Что проверить |
| --- | --- | --- |
| Мастеру не создалась задача | Нет или дублируется активное сопоставление | ID ресурса и активность элемента списка |
| Сообщение в MAX не пришло | Не заполнен `Max ID` или мастер не запустил бота | Профиль пользователя и бот |
| В сделке выбрана неверная СТОА | Ошибка в элементе сопоставления | Компания в списке и тип ресурса |
| Клиент получил сообщение без адреса | Адрес компании заполнен некорректно | Адрес и реквизиты СТОА |
| У мастера нет свободных слотов | Не настроен график ресурса | Рабочие дни, часы и исключения |
| Мастер видит лишние разделы | Ошибка прав экстранета | Роли и доступ к CRM |

- [ ] Экстранет-пользователь активен и не имеет доступа к CRM.
- [ ] Мастер запустил MAX-бота.
- [ ] В профиле заполнен `Max ID`.
- [ ] Ресурс назван по установленному правилу.
- [ ] График ресурса настроен.
- [ ] ID ресурса определен.
- [ ] Создано единственное активное сопоставление.
- [ ] Контрольная запись успешно пройдена.
