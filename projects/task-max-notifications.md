# Уведомления о новых задачах в MAX

Сервер обрабатывает событие Битрикс24 `ONTASKADD` по адресу:

```text
POST https://review.avarcomf.ru/api/b24/task/events?token={TOKEN}
```

После получения события обработчик читает задачу и профиль ответственного. Если в поле пользователя `UF_USR_1785748307515` указан положительный числовой `Max ID`, notice-бот отправляет ответственному название задачи, постановщика, крайний срок и ссылку на карточку задачи. Если поле не заполнено или содержит некорректное значение, отправка пропускается без ошибки.

Повторно доставленное событие не создает второе сообщение. Маркеры успешно отправленных уведомлений хранятся в `storage/task-notifications`. Ошибка MAX не создает маркер, поэтому повтор события может выполнить отправку еще раз.

## Регистрация события

Подписку нужно создать в локальном или OAuth-приложении Битрикс24 с разрешением `task`:

```text
event: ONTASKADD
handler: https://review.avarcomf.ru/api/b24/task/events?token={TOKEN}
```

Метод `event.bind` нельзя вызвать через входящий вебхук. Перед повторной регистрацией нужно проверить существующие подписки методом `event.get`.

## Настройки

- `B24_TASK_MAX_ID_FIELD` — код поля пользователя с `Max ID`; по умолчанию `UF_USR_1785748307515`.
- `B24_TASK_URL_TEMPLATE` — шаблон ссылки с двумя `%d`: ID ответственного и ID задачи.
- `B24_TASK_NOTIFICATION_STORE` — каталог маркеров отправки; по умолчанию `storage/task-notifications`.
- `MAX_BOT_TOKEN_NOTICE` — токен notice-бота MAX.
